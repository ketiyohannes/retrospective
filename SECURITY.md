# Security Policy

## Supported Versions

The latest version on `main` receives security fixes. This project is currently
an MVP and does not maintain older release branches.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting for
`ketiyohannes/retrospective`. Include the affected version, host, reproduction
steps, impact, and any suggested mitigation.

Do not include secrets, private database contents, or exploit details in a
public issue. Acknowledgement and remediation timing depend on severity and
reproducibility.
